# dsh-swipe-turns

DeepSeek Harness（dsh）客户端插件：把同一会话里的问答轮次变成**左右切换的卡片**。

- 平时和原来一样**上下滚动**看完整对话；
- 触控板双指**左右滑**（或触屏左右滑、`Shift` + 滚轮）时，一圈蓝色光晕从屏幕四周向当前这一轮收拢，周围压暗、轻度虚化，收拢到位后进入**卡片模式**；没滑够就松开会散开，上下滚动不会误触发；
- 卡片模式下左右滑动就是翻页：一次滑动只翻一轮，每次都停在这一轮**问题的最顶端**；其他轮次留在背景里，压暗、虚化；
- 翻到第一轮或最新一轮再往外滑，会有橡皮筋式的**限位回弹**，并在底部提示“已经是第一轮 / 已经是最新一轮”；
- 一旦上下滚动，或停止左右操作 3 秒，光晕散开，回到完整对话，位置停在刚才那一轮；
- 右侧竖向的轮次导航改成输入框上方的**横向导航**，两侧有 ‹ › 按钮：悬停看问答预览和时间（如 `9/24 15:27`），点击跳转，浅色刻度是还没加载的更早轮次；
- 发出新问题、出现新轮次时自动切到最新一轮；翻到已加载的最早一轮再往左，会自动加载更早的历史。

插件是纯浏览器端的 DOM 增强，不改 DSH 源码，不需要构建，`lib/` 里就是可以直接加载的文件。

## 安装（桌面客户端）

**方式一：在客户端里装（推荐）**

1. 打开 DSH 客户端，左侧栏进入 **插件**；
2. 点 **安装第三方插件**（或“添加插件”），在输入框里填本文件夹的绝对路径，例如：
   ```
   C:\path\to\dsh-swipe-turns
   ```
3. 安装完成后点 **立即启用**。如果界面没有变化，完全退出客户端再打开。

**方式二：命令行**

先完全退出客户端，然后用客户端自带的 `dsh.cmd`（在安装目录 `resources\runtime\cli\bin\` 下）执行：

```
dsh plugin --profile desktop add C:\path\to\dsh-swipe-turns
```

再打开客户端即可。卸载：`dsh plugin --profile desktop remove dsh-swipe-turns`，或在插件页里卸载。

> 用命令行版 / Web 版（`npx @deepseek-ai/dsh web`）的话，把 `--profile desktop` 换成 `--profile web`。

## 操作说明

| 操作 | 效果 |
|---|---|
| 触控板双指向左滑 / `→` / 底部 `›` | 下一轮（平时先进入卡片模式） |
| 触控板双指向右滑 / `←` / 底部 `‹` | 上一轮（平时先进入卡片模式） |
| 卡片模式下上下滚动 | 立即退出卡片模式 |
| `Shift` + 鼠标滚轮 | 等同横向滑动 |
| 点击底部导航的某个刻度 | 直接跳到该轮（未加载的会先加载） |
| 在底部导航上滚动滚轮 | 轮次很多时横向滚动导航本身 |

- 键盘左右键：输入框里**有文字**时留给光标移动，不会翻卡片；输入框为空或焦点不在输入框时才翻卡片。
- 在代码块、表格这类本身能横向滚动的区域里横向滑动，会先滚动这块内容，不会翻卡片。
- 一次滑动只翻一张，惯性滚动不会连翻。

## 原理

插件依赖 DSH Chat 视图（`@deepseek-ai/dsh-client-ui-chat`）的 DOM 约定：Chat 正文列带 `data-chat-flow`，每个顶层行带 `data-chat-turn="N"`。聚焦时，插件用一个固定定位的浮层画出聚光灯和光晕，再用一条动态样式规则给非当前轮次的行加上随聚焦程度变化的模糊和透明度；翻页时只平移当前这一轮的行，切换后把滚动位置对齐到这一轮问题的顶部。

如果更喜欢取景角标而不是光晕，可以在页面上给 `<html>` 加 `data-dsh-swipe-focus="corners"`。

## 已知限制

- 依赖 DSH 的 DOM 结构（`data-chat-flow`、`data-chat-turn`、`data-conversation-scroll`、`data-composer-seat` 等属性）。DSH 目前是开发者预览版，这些属性如果在后续版本里改名，插件需要跟着改。按 2026-11 的 `0.2.2-rc.1` 源码编写。
- 未加载轮次的刻度没有预览，点击后会逐页加载历史直到该轮。
- 预览取自页面上的文字，回答在流式输出时预览会稍有延迟。
- 没有处理鼠标左键拖拽翻页（会和选中文字冲突）。
